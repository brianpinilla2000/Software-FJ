# SOFTWARE FJ
## Sistema Integral de Gestión de Clientes, Servicios y Reservas

**Universidad Nacional Abierta y a Distancia (UNAD)**  
**Curso:** Programación 213023  
**Fase:** 4

## 1. Descripción del proyecto

Software FJ es un sistema desarrollado en Python que permite gestionar clientes, servicios y reservas mediante programación orientada a objetos.

El proyecto busca organizar los procesos de registro, administración y seguimiento de reservas, aplicando principios de programación y buenas prácticas de desarrollo.

## 2. Objetivo general

Desarrollar un sistema de gestión que permita administrar clientes, servicios y reservas, implementando clases, herencia, encapsulamiento, abstracción, polimorfismo y manejo de excepciones.

## 3. Funcionalidades principales

- Registro y validación de clientes.
- Administración de servicios disponibles.
- Creación y gestión de reservas.
- Confirmación y cancelación de reservas.
- Procesamiento y cálculo de costos.
- Manejo de excepciones.
- Registro de eventos y errores mediante logs.

## 4. Tecnologías utilizadas

- Python 3.
- Visual Studio Code.
- Git.
- GitHub.

## 5. Estructura del proyecto

| Archivo | Descripción |
|---|---|
| `main.py` | Archivo principal de ejecución. |
| `entidades.py` | Clase abstracta Entidad. |
| `cliente.py` | Gestión de clientes. |
| `servicio.py` | Clases de servicios. |
| `reserva.py` | Gestión de reservas. |
| `sistema.py` | Administración del sistema. |
| `registros.py` | Registro de eventos y errores. |

## 6. Ejecución del programa

Para ejecutar el sistema, abre una terminal en la carpeta del proyecto y escribe:

```bash
python main.py
```
